# Data Schema

| Column | Description |
|---|---|
| CustomerID | Unique ID for each customer |
| Age | Customer age (18–65) |
| Gender | Male / Female |
| Tenure | Months the customer has stayed |
| Usage Frequency | How often the customer uses the service each month |
| Support Calls | Number of support calls made |
| Payment Delay | Average number of days payments are late |
| Subscription Type | Basic, Standard, or Premium |
| Contract Length | Monthly, Quarterly, or Annual |
| Total Spend | Total amount spent in USD |
| Last Interaction | Days since last activity |
| Churn | 1 = churned, 0 = stayed |

## Derived/grouped fields

The report states that grouped ranges were created for:
- Tenure
- Support Calls
- Payment Delay
- Last Interaction

These grouped fields were used to make dashboard charts easier to read.
