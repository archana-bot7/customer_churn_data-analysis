# Customer Churn Analysis — Python, SQL & Power BI

A decision-focused customer churn analytics project based on a dataset of **64,374 customers**.

The analysis focuses on:
- Customer profile
- Usage and support behavior
- Payment behavior
- Contract and subscription patterns
- Churn risk segmentation
- Retention recommendations

## Key findings

- Customers analyzed: **64,374**
- Churned customers: **30,493**
- Overall churn rate: **47.4%**
- Revenue at risk: **$15.84M**
- High-risk customers: **12,830**
- Customers with **7+ support calls and 20+ payment-delay days** show **88% churn**
- Monthly contracts have **51.6% churn**, compared with **44.0% quarterly** and **46.2% annual**
